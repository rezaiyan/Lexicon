6 · SRS Algorithm (SM2-like)

7-Level Bucket System

0
Fresh → 1 minute
1
Learning → 10 minutes
2
Familiar → 1 day
3
Building → 3 days
4
Almost → 7 days
5
Strong → 14 days
6
Mastered → 30+ days (grows with easeFactor)

Review Logic

✓ Remembered
repetitions++
if repetitions ≥ successesToAdvance → level++
easeFactor = min(easeFactor + 0.1, 2.5)
nextDue = now + LEVEL_INTERVALS[level]
✗ Forgot
level = max(0, level - forgotPenalty)
repetitions = 0
easeFactor = max(easeFactor - 0.2, 1.3)
nextDue = now + LEVEL_INTERVALS[level]
Presets: EASY / BALANCED (default) / RIGOROUS / EXPERT
Each adjusts successesToAdvance + forgotPenalty

9 · Critical Invariants (never violate)

SRS Algorithm
level ∈ [0, 6]                 always
easeFactor ∈ [1.3, 2.5]      always
interval > 0                 always (even at level 6)
repetitions → 0 on level advance
Analytics Session
startSession() awaited before recordReview()
recordReview() inside sessionId != null guard
endSession() called on complete + onCleared()
sessions map protected by Mutex
Token Refresh
double-check after Mutex acquire
AuthenticationException ≠ transient error
proactive refresh non-blocking
Tag Cascade
deleteTag: remove WordTags BEFORE Tag row
setWordTags: atomic (delete-all + insert)
no addTagToWord() loops in batch ops
use setWordTags() for batch instead
